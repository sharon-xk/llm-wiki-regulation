# 人员页规范 (persons/)

本目录存放**自然人**知识节点，对应纪律处分-人员、机构高管/基金经理等被处罚或涉及违规的自然人主体。

## 与 institutions/ 的区别

| | institutions/ | persons/ |
|---|---|---|
| 主体 | 法人机构 | 自然人 |
| 字段 | 注册资本、法定代表人、机构类型 | 职务、从业资格号、关联机构 |
| 数据来源 | AMAC 机构类处罚 + 证监会机构处罚 | AMAC 人员类处罚 + 证监会个人处罚 |

## 命名

`姓名.md`（如 `张三.md`）。同名人员加机构后缀区分，如 `张三_XX基金.md`。

## Frontmatter 模板

```yaml
---
type: person
name: 张三
gender: 男
org: XX基金管理有限公司        # 关联机构，链接到 institutions/
position: 法定代表人           # 职务：法定代表人/总经理/基金经理/合规负责人 等
qualification_no: P123456789   # 基金从业资格号（如有）
source_count: 1
first_incident: 2024-03
latest_incident: 2024-03
tags: [纪律处分]
---
```

## 正文结构

```markdown
# 张三

## 基本信息
- **姓名**: 张三
- **职务**: 法定代表人 @ [XX基金管理有限公司](../institutions/XX基金管理有限公司.md)
- **从业资格号**: P123456789
- **首次处罚**: 2024-03
- **最近处罚**: 2024-03

## 处罚记录
### 案件 1
- **字号**: 中基协处分(2024)XX号
- **日期**: 2024-03-15
- **违规行为**: ...
- **处罚措施**: 取消基金从业资格

## 违规类型汇总
- [违规类型](../violations/违规类型.md)
```

## 双向链接约定

- 人员页通过 `org` 字段链接到所属机构（`../institutions/`）
- 机构页在"相关人员"段落反向链接到本目录人员
- 同一次处分涉及的机构和人员，通过相同字号关联
